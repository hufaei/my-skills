# my-skills

Personal Codex skills.

## Included skills

### `chatgpt-pro-engineering`

Runs an engineering workflow in which local Codex owns repository analysis,
implementation, and testing, while the logged-in web ChatGPT Pro provides
initial technical oversight and an independent final review.

This skill is manual-only. Invoke it explicitly with:

```text
$chatgpt-pro-engineering <requirement and acceptance criteria>
```

## Install

Place or symlink the desired skill directory under your Codex user skills
directory, normally `~/.codex/skills/`.
